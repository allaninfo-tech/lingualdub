# Research Challenge Modules

This directory contains workspaces for the framework's open research challenges.
Each module is an area the framework is designed to host and support — they are
active investigations, not solved problems.

| Module | Directory | Priority | Dependency |
|---|---|---|---|
| Temporal alignment | `temporal_alignment/` | Near-term | — |
| Code-switching | `code_switching/` | Near-term | — |
| Voice-retention evaluation | `voice_retention_eval/` | Near-term | — |
| Cross-lingual voice transfer | `voice_transfer/` | Open-ended | Voice-retention evaluation |
| Audio-visual synchronisation | `av_sync/` | Mid-term | Temporal alignment |

Each module directory contains its own README with baseline definition,
current status, and done-when criteria.
