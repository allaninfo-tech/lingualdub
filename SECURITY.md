# Security Policy

## Supported Versions

We release patches for security vulnerabilities for the following versions:

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |
| < 0.1.0 | :x:                |

## Reporting a Vulnerability

We take the security of LingualDub and the privacy of voice datasets seriously.

If you believe you have found a security vulnerability in LingualDub, please do **not** open a public issue. Instead, report it privately via one of the following channels:

- **GitHub Private Vulnerability Reporting**: Use the "Report a vulnerability" button under the **Security** tab of this repository.
- **Email**: Send details to `security@lingualdub.org` (or contact project maintainers).

### What to Include in Your Report

Please provide as much information as possible to help us reproduce and address the issue:
1. Description of the vulnerability and its potential impact.
2. Steps to reproduce the issue (including minimal proof-of-concept code).
3. The version of LingualDub and Python environment where the issue was observed.
4. Any potential mitigations or workarounds you are aware of.

### Response Timeline

- **Initial Acknowledgement**: Within 48 hours.
- **Triage & Status Update**: Within 5 business days.
- **Disclosure Policy**: We follow coordinated disclosure. Once a fix is ready, we will release a patch and publish a security advisory.
